## Ground-truth identity

`expected_reconciliation.csv` contains separate `ORDER` and `SETTLEMENT` results. Use `result_scope` plus `work_key` as the stable logical identity. Normal order keys are merchant order IDs; normal settlement keys are external batch IDs. Invalid-row and bank-only keys use explicit synthetic prefixes. Blank monetary differences represent null, not zero.
